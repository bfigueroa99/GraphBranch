      Settings

      Without a token, GitHub allows 60 requests per hour. With a read-only fine-grained token (Metadata, Contents and Pull requests permissions) the view refreshes every 10 seconds, works with repositories that have thousands of branches, and you can see private repos.

      The token is stored only in this browser and is sent only to api.github.com.

      For private gitlab.com projects: a personal access token with the read_api scope. Public projects don't need one.

      The token is stored only in this browser and is sent only to gitlab.com.

      For private repos on codeberg.org: an access token with the read:repository scope. Public repos don't need one.

      The token is stored only in this browser and is sent only to codeberg.org.

      For private repos on bitbucket.org: a repository or workspace access token with the repository scope. Public repos don't need one.

      The token is stored only in this browser and is sent only to bitbucket.org.

      Notices to Slack, Discord and Teams

      Each webhook gets the events you tick: releases, merges to the default branch, CI turning red and force-pushes on it. The URL is a secret: it is stored encrypted on this computer and is sent only to its own service.

      Flags on tagged commits and a plate on the commit each environment (production, staging) runs. Two more requests when a repository opens, then two every 15 minutes.

      GraphBranch shows every branch of the repo, the most active ones closest to the default branch. On large repos they appear gradually, most active first. Pinned branches (click a branch → Pin) go right below the default branch, even with a filter. Use the graph filter to focus on a prefix, for example release/.

      Trophies

        Achievements celebrate what the repository and the team accomplish, never individual people. They are saved only in this browser.

        Repo health

        Calculated only from what is already loaded, with no extra requests, and updated live. It describes the repository, never people. Closed logbooks are saved only in this browser.

        Autonomous loop prompt

        Paste it into a Claude Code Routine (one iteration per run, every few hours) or into a session. The first run sets up the loop in the repository (LOOP.md) and the next ones follow it and improve it, like the Brunell_Node loop. It works for any project.

        If you set one, the loop never touches it: only you promote to it.

        Text view

        The branches and their latest commits as a tree. Up and Down move, Right and Left open and close a branch, Enter shows it in the graph.

        Constellation

        Each followed repository is a galaxy: the bigger, the more commits loaded. Tab moves between them and Enter opens it.

        Search commits

        Search by message, SHA or author (@name). Down arrow goes to the results, Enter flies to the commit.
