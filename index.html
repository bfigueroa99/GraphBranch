    Settings

    Without a token, GitHub allows 60 requests per hour. With a read-only fine-grained token (Metadata, Contents and Pull requests permissions) the view refreshes every 10 seconds, works with repositories that have thousands of branches, and you can see private repos. The token is stored only in this browser and is sent only to api.github.com.

    On large repos GraphBranch does not list every branch: it shows the default branch, the ones you pin (click a branch → Pin) and those with the most recent commits. Use the graph filter to focus on a prefix, for example release/.
