    Settings

    Without a token, GitHub allows 60 requests per hour. With a read-only fine-grained token (Metadata, Contents and Pull requests permissions) the view refreshes every 10 seconds, works with repositories that have thousands of branches, and you can see private repos.

    The token is stored only in this browser and is sent only to api.github.com.

    GraphBranch shows every branch of the repo, the most active ones closest to the default branch. On large repos they appear gradually, most active first. Pinned branches (click a branch → Pin) go right below the default branch, even with a filter. Use the graph filter to focus on a prefix, for example release/.

    Trophies

      Achievements celebrate what the repository and the team accomplish, never individual people. They are saved only in this browser.
